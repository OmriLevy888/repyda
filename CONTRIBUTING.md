# Contributing

For people who wish to help promote this project:

1. Until a well formed CI/CD process exists, all code must be reviwed by the repository owner.
2. Branch names can be anything you'd like, as long as they contain the issue number they refer to.
3. Each milestone has its own parent branch, work off of it.
4. If your issue is not part of a milestone, branch off of `dev`.
5. Have fun and thanks for your help :)
